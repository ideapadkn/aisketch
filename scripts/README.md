# Цифры на сайте — из Instagram, автоматически

Все числа на сайте (блок «Raqamlar», первый экран, счётчики на роликах) берутся из `assets/stats.js`.
При каждой публикации — после пуша в `main` и каждое утро в 08:00 по Ташкенту — workflow `.github/workflows/site.yml`
запускает `scripts/update-stats.mjs`. Скрипт забирает из Instagram свежие данные и подставляет их в этот файл.

Что показывается:
- просмотры и охват за последние 30 дней;
- доля просмотров от неподписчиков;
- топ-5 роликов по просмотрам и счётчики на карточках роликов;
- дата, на которую актуальны данные.

Пока токен не настроен, сайт показывает цифры, записанные в `assets/stats.js` в git. Их можно поменять руками.

## Безопасность в открытом репозитории

Токены хранятся в **Secrets** репозитория. Они зашифрованы и не видны в коде, в логах и в форках.
В открытый код попадает только скрипт, который читает токен из переменной окружения.
Сам токен **никогда** не вставляйте в файлы и коммиты.

## Настройка (один раз, ~15 минут)

### 1. Приложение Meta и токен Instagram

Связывать Instagram с Facebook-страницей **не нужно**: используется «Instagram API with Instagram Login».
Facebook-аккаунт нужен только для входа в кабинет разработчика. Подойдёт любой личный, даже новый,
и к Instagram он не привязывается.

1. Зайдите на https://developers.facebook.com, нажмите **Get started** и подтвердите телефон и почту.
2. **My Apps → Create app**, тип **Business**.
3. В меню приложения откройте **Instagram → API setup with Instagram business login**.
4. Убедитесь, что среди разрешений есть `instagram_business_manage_insights`. Если нет — добавьте.
5. Напротив аккаунта нажмите **Generate token**, войдите в `aisketchuz` и скопируйте токен.
   Если Meta попросит добавить аккаунт тестировщиком, примите приглашение в Instagram:
   **Настройки → Приложения и сайты → Приглашения тестировщикам**.

### 2. Токен в GitHub

Репозиторий → **Settings → Secrets and variables → Actions → New repository secret**:
- Name: `IG_TOKEN`
- Secret: токен из шага 1.

### 3. Публикация через GitHub Actions

1. **Settings → Pages → Build and deployment → Source: GitHub Actions**.
2. Проверьте, что в **Custom domain** по-прежнему указан `aisketch.uz`.
3. **Actions → Site → Run workflow**.

Через минуту под графиком на сайте будет сегодняшняя дата: «Manba: Instagram Insights, … holatiga».

### 4. Чтобы токен не истекал (рекомендуется)

Токен Instagram действует 60 дней. По понедельникам workflow сам продлевает его, если есть второй секрет:

1. GitHub → аватар → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
2. **Repository access → Only select repositories →** `aisketch`.
3. **Permissions → Repository permissions → Secrets: Read and write**.
4. Срок действия поставьте максимальный.
5. Сохраните этот токен как секрет репозитория `GH_PAT`.

Без `GH_PAT` раз в 2 месяца придётся заново выполнить шаг 1.5 и обновить `IG_TOKEN`.

## Если цифры перестали обновляться

GitHub пришлёт письмо о том, что упал workflow **Site**. Сайт при этом всё равно опубликуется с последними цифрами.
Чаще всего причина в том, что истёк токен: повторите шаги 1.5 и 2.

## Счётчики на карточках роликов

Карточка ролика в `index.html` ищет свой ролик по имени из `data-name` в первой строке подписи в Instagram.
Если не находит, добавьте карточке `data-ig="КОД"`, где КОД — часть адреса ролика `instagram.com/reel/КОД/`.
